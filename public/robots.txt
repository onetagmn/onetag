# OneTag — crawler access rules
#
# Two layers of intent here:
# 1. Named AI training/scraping bots are blocked from the entire site,
#    regardless of path. Reputable AI companies (Anthropic, OpenAI, Google,
#    etc.) publicly commit to honoring this for their crawlers.
# 2. Everyone else (regular search engines like Googlebot/Bingbot) may only
#    index the public marketing page — never the app itself. Admin, staff,
#    and parent tools require login anyway, and child profile pages must
#    never be indexable, for obvious privacy reasons.
#
# IMPORTANT: robots.txt is a voluntary convention, not real security. It
# does not and cannot prevent a human or a non-compliant scraper from
# directly opening a URL. Actual protection for sensitive endpoints comes
# from authentication (login + session checks), not from this file.
