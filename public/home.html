FAQ

Common questions

 

Does a finder need to install an app?▾
No. Tapping the wristband opens a normal web page in any browser — nothing to install.
Is our child's information safe?▾
Only essential emergency details are public. Editing a profile always requires a one-time code sent to the parent, and the parent's phone number is never shown to a finder.
What happens if the wristband is lost?▾
A school admin can deactivate a lost tag and issue a new one from the dashboard in minutes.
What does OneTag cost?▾
Pricing depends on the number of students and deployment scale. Contact us for a quote tailored to your school.
Which languages are supported?▾
OneTag is available in Mongolian, English, and Japanese today, with more languages planned.
